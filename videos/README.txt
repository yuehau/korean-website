📹 HOW TO ADD YOUR VIDEOS
===========================

Drop your recorded video files into this folder using these EXACT filenames.
The website finds them automatically — no HTML editing needed. Just refresh.

VOCABULARY VIDEOS (Vocabulary page):

  member1.mp4   →  Hui Yee   (Food: 비빔밥, 불고기, 김치, 김밥)
  member2.mp4   →  Yun Yi    (Food: 떡볶이, 라면, 피자, 샌드위치)
  member3.mp4   →  Yi Hong   (Numbers 0–4: 하나, 둘, 셋, 넷, 공)
  member4.mp4   →  Yue Hao   (Numbers 5–9: 다섯, 여섯, 일곱, 여덟, 아홉)

DIALOGUE / SHORT SCENE VIDEO (Dialogue page):

  dialogue.mp4  →  Group role-play scene (1–3 minutes)

CHECKLIST BEFORE UPLOADING:
  ✔ MP4 format (H.264) — works in every browser. Avoid MOV or AVI.
  ✔ Keep each vocab video under ~50 MB so the page loads fast.
    (If your phone recording is bigger, compress it free at handbrake.fr
     or use an online compressor.)
  ✔ Own voice + face visible (coursework requirement).
  ✘ NO AI-generated voices — automatic 0 marks per the coursework rules.

AFTER ADDING THE FILES:
  1. Open the website and check each video plays.
  2. If publishing to GitHub Pages: upload the videos to the same
     videos/ folder in your GitHub repository, then wait 1–2 minutes.
     ⚠ GitHub blocks single files over 100 MB — compress first if needed.

WRONG FILENAME? If a video doesn't appear, check the filename matches
exactly (lowercase, no spaces): member1.mp4 … member4.mp4, dialogue.mp4
